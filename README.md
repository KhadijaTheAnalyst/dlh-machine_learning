# dlh-machine_learning

Machine Learning pipeline project built as part of the **AI Academy at Digital Learning Hub Luxembourg**, following the Holberton School ML Engineering curriculum.

## Overview

This repository covers the end-to-end lifecycle of a machine learning project — from raw data ingestion and preprocessing through model training, evaluation, and deployment-ready pipelines.

## Topics Covered

- **Databases & Data Storage** — Connecting to and querying structured data sources
- **Data Processing** — Cleaning, transforming, and feature engineering with pandas and NumPy
- **Exploratory Data Analysis (EDA)** — Statistical summaries and visualizations
- **Model Building** — Training and tuning ML models using scikit-learn
- **Pipeline Construction** — Automating the full ML workflow
- **Model Evaluation** — Metrics, cross-validation, and performance analysis

## Tools & Technologies

| Tool | Purpose |
|------|---------|
| Python 3 | Core language |
| pandas / NumPy | Data manipulation |
| scikit-learn | Machine learning models |
| matplotlib / seaborn | Visualization |
| SQL | Data extraction |
| Git & GitHub | Version control |

## Structure

Each module or subdirectory corresponds to a phase of the ML pipeline as structured by the curriculum.
