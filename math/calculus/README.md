# Calculus

This directory contains the **Calculus** project from the DLH AI Academy (Holberton ML Engineering curriculum). It covers the mathematical foundations used throughout machine learning: summation and product notation, series, derivatives, and integrals.

The tasks are a mix of multiple-choice questions (where the answer file contains only the number of the correct option) and Python functions that implement calculus operations programmatically.

---

## Learning Objectives

By the end of this project, I should be able to explain each of the following without external help:

- Summation and Product notation
- What is a series?
- Common series
- What is a derivative?
- What is the product rule?
- What is the chain rule?
- Common derivative rules
- What is a partial derivative?
- What is an indefinite integral?
- What is a definite integral?
- What is a double integral?

---

## Requirements

### Multiple-choice files
- A file containing only the number of the correct answer, ending with a new line.

### Python scripts
- All files are interpreted/compiled on Ubuntu 20.04 LTS using `python3` (version 3.9)
- All files end with a new line
- The first line of every script is exactly `#!/usr/bin/env python3`
- Code follows `pycodestyle` (version 2.11.1)
- All modules, classes, and functions have documentation
  (`python3 -c 'print(__import__("my_module").__doc__)'`)
- All files are executable
- No external imports are allowed unless explicitly stated
- Modules that use `numpy` must import it as `import numpy as np`
