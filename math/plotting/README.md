# Plotting

This directory contains the **Plotting** project from the DLH AI Academy (Holberton ML Engineering curriculum). It covers data visualization using `matplotlib`, building progressively from basic line plots to complex multi-panel figures.

---

## Learning Objectives

By the end of this project, I should be able to explain each of the following without external help:

- What is a plot?
- What is a scatter plot? line graph? bar graph? histogram?
- What is `matplotlib`?
- How to plot data with `matplotlib`
- How to label a plot (title, axis labels, legend)
- How to scale an axis
- How to plot multiple sets of data on the same figure

---

## Requirements

- All files are interpreted/compiled on Ubuntu 20.04 LTS using `python3` (version 3.9)
- All files end with a new line
- The first line of every script is exactly `#!/usr/bin/env python3`
- Code follows `pycodestyle` (version 2.11.1)
- All modules, classes, and functions have documentation
- All files are executable
- Modules used: `numpy`, `matplotlib`

## Files

| Task | File | Description |

| 0. Line Graph | `0-line.py` | Plot y = x³ as a solid red line |

| 2. Change of Scale | `2-change_scale.py` | Line graph with logarithmic y-axis |

| 5. All in One | `5-all_in_one.py` | All previous plots in a single figure using subplots |
