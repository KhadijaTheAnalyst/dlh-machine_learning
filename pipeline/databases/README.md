# Databases Project

## Overview
This project covers **Relational Databases (MySQL)** and **Non-Relational Databases (NoSQL/MongoDB)**.

We will work with:
- **MySQL 8.0** - SQL queries, stored procedures, triggers, views, and indexes
- **MongoDB 4.4** - Document storage, flexible schemas, and aggregation
- **Python 3.9** - PyMongo for database interactions

## Learning Objectives
- Understand relational vs. non-relational databases
- Write and optimize SQL queries with indexes
- Create stored procedures, functions, triggers, and views in MySQL
- Learn NoSQL concepts and MongoDB querying
- Implement ACID principles
- Use Python to interact with both databases

## Requirements
- MySQL 8.0
- MongoDB 4.4
- Python 3.9 with PyMongo 4.6.2
- pycodestyle 2.11.1
